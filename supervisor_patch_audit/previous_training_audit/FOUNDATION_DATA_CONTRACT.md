# Foundation V1 export -> successor-model cache contract

Authoritative read-only source: foundation_v1/audit.py observation()/export(), full_campaign.export_scope(), common geometry/plan helpers and immutable profiles/workloads/contexts/canonical_contract.json. Exact paths/hashes are in REFERENCE_FILES.json.

TRAIN400 workloads/1600 tasks/400000 rows; DEVELOPMENT50/200/50000; LOCKED_SYNTHETIC_TEST50/200/50000. Each workload has N250/1000 x U.6/.8. Each task has150 Phase-A +4*20 adaptive unique seed20 geometries, then10 geometries repeated at seeds21 and22. Thus230 unique inputs+20 repeat-realization rows=250/task;500 workloads,2000 tasks,500000 eventual rows. Collector science and master Phase-A SHA remain unchanged.

Canonical exports are separate partition directories containing foundation_v1_master_observations.csv.gz plus dataset/provenance manifests. The loader recursively chooses TRAIN/DEVELOPMENT/LOCKED individual files and ignores TRAIN_DEV duplicates. No SQLite/worker/receipt input is accepted as a training export. A complete real corpus must pass all quotas; tiny inputs require explicit --fixture and remain marked in every cache/run result.

Required columns are listed in flexmodels.data.REQUIRED: Plan_Row_ID,Base_Geometry_ID,Task_ID,Workload_ID,split,hardware_class,Profile_IDs,J,N,U,x,simulation_seed,Candidate_Source,Adaptive_Wave,mean_tracking,p90,Pj,objective,evidence_counts,input_status,observation_status,evidence_status,raw_results. CSV nested arrays/dicts use JSON, never eval. Task_ID exactly matches Workload_ID__N{N}__U{round(100*U):03d}. x is(Pbar,R,w1..wJ) in kW/server. Job identity/order/QoS come from the immutable workload/profile manifests, not inferred from a filename. Foundation actually contains J2,3,4,5,6; the fixture covers J2/4/6. Hardware P100/A100 must agree with every profile. Shared measured grounding anchors may appear across partitions as the approved design allows; SYN_ profile partitions must match and are not silently shared.

Legal domain derives separately from each physical workload: Pmin=min profile min power/1000,Pmax=max profile max power/1000; Pbar in[.9*Pmin,Pmax], R>=.01,R<=.6*Pbar,Pbar+R<=1.2*Pmax,Pbar-R>=0. Weights sum1 and use requested[.6/J,1.8/J] intersected with legacy/server-count/bounded-simplex limits. The training package performs no new optimization or coordinate generation.

Only LEGAL_INPUT + VALID_OBSERVATION + SUFFICIENT_JOB_TYPE_EVIDENCE rows are accepted. QoS vector/evidence length must equal J, every count positive and every physical/scientific value finite. Missing jobs are not zero probability. Duplicate Plan_Row_ID, duplicate realization/group and conflicting candidate vectors within(Task_ID,Base_Geometry_ID) are rejected. A repeat group must contain exactly seed20 alone or20/21/22; base20 is mandatory.

raw_results supplies Simulator_Power_Cost,R_actual_watts,Mtrack_Price_Coefficient_piE,Mtrack_Hour_Seconds,Pbar_ratio,R_ratio. This preserves actual integer-watt quantization and serialized six-decimal ratio features. M_track=R_actual_watts*mean*piE*hour; M_RSR=M_power+M_track. Full objective adds softplus(10*(p90-.3)) and20*sum softplus(2*(Pj-.1)). Canonical constants are centralized in objective.py and tested against canonical_contract.json. Numerical feasibility uses equality-inclusive p90<=.30 and every configured Pj<=.10.

Cache: one cache.pt tensor bundle plus manifest.json. Includes normalized padded job features,explicit boolean masks,14 globals,raw/transformed behavior labels,objective reconstruction coefficients,normalized input geometry,all row/task/workload/profile/hardware/context/source/wave/seed/split identities. Cache manifest hashes inputs,canonical source sidecars,physical manifests and the tensor bundle. The original export remains authoritative. Features/target std fit TRAIN only; DEVELOPMENT/LOCKED statistics are forbidden.

Ordinary episodes choose one Task_ID,seed20 only,and disjoint Base_Geometry context/query groups. K=0..64,Q32 default. The old export manifest's allowed_future_K documentation stops at32; the approved new project explicitly extends evaluation to64, which fits230 unique inputs with disjoint32-query sets. No collector artifact is modified for this metadata difference. Repeats remain available for group-normalized Baseline sampling and separate noise/scenario diagnostics; they never masquerade as independent spatial query geometries.

This preflight has NOT validated a completed real500000-row export because collection may be incomplete. The code's full-corpus gate rejects fixtures without --fixture. All actual development execution uses synthetic rows only. No real Foundation outputs were read into training.
