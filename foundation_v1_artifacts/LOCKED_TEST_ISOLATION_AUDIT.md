# Sealed synthetic-test policy

LOCKED_SYNTHETIC_TEST is predeclared and operationally isolated, but simulator outcomes are precomputed in the same campaign before model development. Unlock explicitly authorizes collection, not fitting/tuning. Never use locked rows for Meta V4/FlexPFN fitting, architecture/hyperparameter selection, normalization or ordinary train/dev reports. Separate ledgers/raw roots/exports persist. Future completely new real-family profiles remain the strongest untouched external holdout. This is operational isolation, not adversarial filesystem access control.
